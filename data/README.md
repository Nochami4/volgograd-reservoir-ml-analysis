# Данные

В проекте используются данные наблюдений за состоянием и изменением береговой линии Волгоградского водохранилища.

Исходные материалы были предоставлены для выполнения учебно-исследовательской работы. Оригинальные файлы не публикуются в репозитории.

В анализе использовались данные о:

- положении и изменении береговой линии;
- береговых профилях;
- уровнях воды Волгоградского водохранилища;
- метеорологических условиях;
- характеристиках исследуемых участков.

Каталоги `raw`, `interim`, `processed` и `delivery` используются локально и исключены из Git.
