# Результаты анализа

В публичной версии репозитория сохранена только выборка итоговых результатов проекта:

- ключевые визуализации исследовательского анализа и моделирования;
- агрегированные метрики моделей;
- краткие сводки нейросетевых экспериментов.

Полные промежуточные выгрузки, построчные прогнозы, диагностические таблицы и другие сгенерированные материалы хранятся только локально и не включаются в репозиторий.
